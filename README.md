# Syntecxhub Data Cleaning Utility

## Project Overview

This project is part of the Syntecxhub Data Science Internship Week 1 tasks.

The project focuses on cleaning and preparing a dataset using Python and Pandas.

## Data Cleaning Steps

- Detected missing values
- Filled missing Calories values using the median
- Filled the missing Date value using the surrounding date sequence
- Converted the Date column to datetime format
- Fixed an incorrectly formatted date
- Removed duplicate records
- Standardized column names to lowercase
- Created a cleaning log
- Saved the cleaned dataset as a CSV file

## Final Dataset

- Original rows: 32
- Rows after cleaning: 31
- Columns: 5
- Missing values after cleaning: 0
- Duplicate rows after cleaning: 0

## Files

- `data.csv` – Original dataset
- `cleaned_data.csv` – Cleaned dataset
- `cleaning_log.csv` – Cleaning steps and actions
- `Syntecxhub_Project_Data_Cleaning_Utility.ipynb` – Complete Python/Colab notebook
